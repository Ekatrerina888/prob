# Sprint\_5

# Автотесты для сервиса Stellar Burgers. Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.

# Файлы:

* tests/ - каталог с автотестами
* tests/test\_01\_registration.py - файл с проверками Регистрации
* tests/test\_02\_login.py - файл с проверками Входа
* tests/test\_03\_profile.py - файл с проверками Личного кабинета, переходов и выхода из аккаунта
* tests/test\_04\_constructor.py - файл с проверками Раздела "Конструктор"
* conftest.py - файл с фикстурами
* data.py - данные для авторизации/регистрации
* locators.py - файл с локаторами
* urls.py - файл с адресами URL

# Регистрация

* Успешная регистрация
* Ошибка при некорректном пароле
